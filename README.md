# StockMesh

StockMesh is an early-stage, context-aware network analysis project. Its first practical domain is company social networks: people, cross-department relationships, behavior patterns, timelines, events, statements, and stances. Its wider research horizon includes communities, institutions, resource and energy systems, biological collectives, AI/machine collectives, and other macro networks.

The name StockMesh is a tribute to Stockfish; StockMesh does not use Stockfish source code.

The project is currently in **discovery / definition**. No product implementation or technology stack has been adopted yet.

## Working principles

- Preserve source context and provenance; distinguish observations from inference.
- Treat model-generated interpretations as hypotheses, not facts.
- Make uncertainty, contradiction, and missing evidence visible.
- Minimize harm: access control, purpose limitation, and human review are product requirements, not later polish.
- Keep raw or sensitive datasets outside Git.
- Keep conversation locators and concrete cases out of this public repository. A case may be published only as an explicitly authorized, de-identified template.

## Repository state

This initial repository establishes the governing product-document chain. The next product milestone is to validate a narrow company-network analysis workflow using synthetic or explicitly authorized data.
